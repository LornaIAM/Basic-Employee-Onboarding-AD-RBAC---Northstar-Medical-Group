# Basic Employee Onboarding (AD)(RBAC)

## Northstar-Medical-Group
Active Directory infrastructure rebuild for a fictional company called “Northstar Medical Group”. Includes domain setup, organizational structure, user provisioning, RBAC implementation, and incident resolution

## Problem Statement
Northstar Medical Group was using an MSP (Managed Service Provider) to handle their infrastructure and run their IT operations. At the time Northstar Medical Group was smaller and did not have the bandwidth to handle these processes. Fast forward, the Group has grown and along with their growth the strain on their infrastructure and IT Operations with the MSP has become more apparent. The Active Directory was completely unorganized; there was no structure to adding users which consistently caused inconsistent access for the employees. That then trickled down to causing departments to become very unorganized. Along with the internal issues the onboarding and offboarding issues were also a disaster. These problems then put Northstar Medical Group in a very vulnerable position to potentially face non-compliance with HIPPA regulations that could expose the facility to federal enforcement actions and substantial civil monetary penalties from the Office for Civil Rights (OCR)
